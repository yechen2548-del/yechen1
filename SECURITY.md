# Security Policy

## Supported versions

Only the latest contents of the default branch are supported while this project is pre-release.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Contact the repository owner privately through the security contact configured for the GitHub repository, or use GitHub's private vulnerability reporting if it is enabled.

Reports should include a concise description, affected file or behavior, reproduction steps, and a suggested mitigation when available. Do not include real credentials, tokens, private URLs, or personal data in the report.

## Repository hygiene

This repository must not contain API keys, tokens, passwords, connection strings, private configuration, `.env` files, generated Unity folders, or third-party assets without clear redistribution rights.
